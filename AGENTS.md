# ESSAYSCAFF PROJECT RULES

These rules are permanent. Every contributor (human or AI) must follow them.

1. Never fabricate NLP results.
2. Never fabricate scores.
3. Never fabricate accuracy values.
4. Never fabricate confusion matrices.
5. Never fabricate processing timings.
6. Do not use generative AI to write student essays.
7. Student authorship must be preserved.
8. Every important detector must be explainable.
9. Every important output must be traceable to its source.
10. Research-critical formulas must be centralized and documented.
11. Heuristic detectors must be labeled honestly.
12. Do not replace functioning architecture unnecessarily.
13. Run tests after research-critical modifications.
14. A feature is not considered complete until it has been executed and verified.
